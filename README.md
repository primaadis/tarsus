# K-Pedia Mobile - Tarif Khusus Kereta Api
Aplikasi mobile React Native & Expo untuk informasi tarif khusus kereta api PT KAI.
Pengembang: Prima Adi Saputra

## Cara Menjalankan Aplikasi di Android & iOS

1. Pastikan Node.js sudah terinstal.
2. Buka terminal di folder ini, lalu jalankan:
   ```bash
   npm install
   ```
3. Jalankan server Expo:
   ```bash
   npx expo start
   ```
4. Buka aplikasi **Expo Go** di HP Android Anda (scan QR code) atau iPhone (scan dengan kamera).
5. Untuk build APK Android mandiri:
   ```bash
   npx eas build -p android --profile preview
   ```
